# TaGunner RT + PostFX Lab

Experimental Android app for checking Vulkan Ray Tracing features and comparing screenshot PostFX with OpenGL ES.

## Build APK

Use GitHub **Actions → Build TaGunner RT PostFX APK → Run workflow**, or push a commit to `main`. Download the APK artifact after a successful build.

This is **not** a Roblox graphics injection app. Its ray tracing probe checks the device's real driver; it doesn't enable RTX inside Roblox.
